## Engineering principles

```text
Product clarity       → Build around a real user workflow
Trustworthy systems   → Validate inputs, isolate concerns, handle failure explicitly
Maintainable code     → Prefer typed contracts, small modules, and predictable data flow
Responsible AI        → Keep context scoped, behavior observable, and limitations visible
Polished UX           → Make accessibility, responsiveness, and feedback part of the design
```

## Architecture focus

I prefer systems that are easy to understand and safe to evolve:

- **Presentation layer:** responsive React interfaces with accessible, reusable components.
- **Application layer:** explicit use cases and typed boundaries instead of UI-driven business logic.
- **Integration layer:** isolated adapters for AI providers, Telegram, web crawling, storage, and external APIs.
- **Data layer:** validated schemas, normalized persistence, scoped access, and migration-friendly design.
- **Delivery:** environment-based configuration, reproducible scripts, and documentation that explains trade-offs.
